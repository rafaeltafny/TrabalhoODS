# Tecnologia para o Impacto Social — Programação Orientada a Objetos
**Estudante:** Tafny Rafael

Este repositório contém três soluções de software orientadas a objetos alinhadas aos Objetivos de Desenvolvimento Sustentável (ODS) da ONU:

1. **`01_artesao_digital/` (ODS 8 e ODS 9 — Trabalho Decente, Inovação e Infraestrutura):** Hub que conecta cooperativas de artesãos a designers voluntários, calculando preço justo e repasse integral.
2. **`02_olho_dagua/` (ODS 6 — Água Potável e Saneamento):** Plataforma comunitária para monitoramento de nascentes, análise de qualidade da água e denúncias de vazamento de esgoto.
3. **`03_guardioes_mar/` (ODS 13 e ODS 14 — Ação Climática e Vida na Água):** Central de monitoramento costeiro para limpeza de praias, redes fantasma e denúncias de pesca ilegal.

## Como executar
Cada pasta possui código executável em Python 3.10+ sem dependências externas:
```bash
python 01_artesao_digital/main.py
python 02_olho_dagua/main.py
python 03_guardioes_mar/main.py
```
